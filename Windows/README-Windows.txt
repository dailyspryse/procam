ProCam Studio für Windows
=========================

1. ZIP-Datei vor dem Entpacken entsperren: Rechtsklick → Eigenschaften →
   unten "Zulassen"/"Unblock" anhaken → OK. Dann entpacken, z. B. nach C:\ProCam.
2. ProCamStudio.exe starten.
   Falls Windows "Der Computer wurde durch Windows geschützt" zeigt:
   "Weitere Informationen" → "Trotzdem ausführen" (die App ist nicht signiert).
   Firewall-Abfrage: "Private Netzwerke" erlauben, sonst wird das iPhone nicht gefunden.
3. ProCam auf dem iPhone öffnen – gleiches WLAN. Das iPhone erscheint oben links.
   Wird es nicht gefunden: die IP-Adresse vom iPhone-Bildschirm unter "Direkt per IP" eintragen.
4. Oben rechts "Webcam einrichten" → Windows fragt einmal nach Admin-Rechten.

Windows 11: Die Kamera heißt "ProCam iPhone (Windows Virtual Camera)" und ist in
ALLEN Apps sichtbar – Kamera-App, Browser, Discord, Teams, Zoom, OBS.
Voraussetzung: Einstellungen → Datenschutz und Sicherheit → Kamera →
"Kamerazugriff" und "Desktop-Apps den Zugriff auf die Kamera erlauben" an.

Windows 10: Die Kamera heißt "ProCam iPhone" und ist in Zoom, OBS, Discord und
Browsern sichtbar (nicht in der Kamera-App).

Apps, die beim Einrichten schon liefen, komplett beenden (auch aus dem
Infobereich unten rechts, z. B. Discord) und neu starten.

Bedienung
- Klick ins Bild: Fokus · Alt + Klick: Belichtung messen
- Strg+Alt+Z Zebra · Strg+Alt+P Focus Peaking · Strg+Alt+C Falschfarben · Strg+Alt+G Raster
- Doppelklick auf einen Regler setzt ihn zurück
- Fehlerprotokoll: %APPDATA%\ProCam\errors.log
