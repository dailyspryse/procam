ProCam Studio für Windows
=========================

1. ZIP an einen festen Ort entpacken, z. B. C:\ProCam
   (nicht im Download-Ordner lassen: die Webcam merkt sich den Pfad).
2. ProCamStudio.exe starten.
   Falls Windows "Der Computer wurde durch Windows geschützt" zeigt:
   "Weitere Informationen" → "Trotzdem ausführen" (die App ist nicht signiert).
3. ProCam auf dem iPhone öffnen – gleiches WLAN. Das iPhone erscheint oben links.
   Wird es nicht gefunden: die IP-Adresse vom iPhone-Bildschirm oben links
   unter "Direkt per IP" eintragen.
4. Oben rechts "Webcam einrichten" → Windows fragt einmal nach Admin-Rechten.
   Danach in Zoom, Teams, OBS, Discord … die Kamera "ProCam iPhone" wählen.
   Apps, die schon offen waren, einmal neu starten.

Wird der Ordner verschoben: "Webcam einrichten" einfach nochmal klicken.
Firewall-Abfrage beim ersten Start: "Private Netzwerke" erlauben, sonst
findet ProCam das iPhone nicht.

Bedienung
- Klick ins Bild: Fokus · Alt + Klick: Belichtung messen
- Strg+Alt+Z Zebra · Strg+Alt+P Focus Peaking · Strg+Alt+C Falschfarben · Strg+Alt+G Raster
- Doppelklick auf einen Regler setzt ihn zurück
- Fehlerprotokoll: %APPDATA%\ProCam\errors.log
